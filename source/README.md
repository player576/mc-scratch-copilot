# MC Scratch Copilot

This folder contains a desktop app prototype and a Forge 1.20.1 MDK scaffold.

## Structure
- `desktop-app/` — Electron + Blockly editor
- `forge-mdk/` — Forge MDK structure for Java mod development

## Start

Windows:
```bat
run.bat
```

Linux/macOS:
```bash
chmod +x run.sh
./run.sh
```
